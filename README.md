# install neovide

```
mkdir -p ~/.local/bin

wget -O ~/.local/bin/neovide \
  https://github.com/neovide/neovide/releases/latest/download/neovide.AppImage

chmod +x ~/.local/bin/neovide
```

ya pkg add mingo99/tokyonight
